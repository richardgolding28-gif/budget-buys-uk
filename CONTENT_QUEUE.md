# Content queue

This is the list the automated posting job works through, one topic per run, top to bottom. When a topic is published, move it to "Done" so it's never repeated.

Each new post should follow the exact structure of the existing posts in `_posts/`: disclosure include at top, "what actually matters" section, 4-5 picks using the `amazon-link.html` include with a real, current UK product name (look it up on amazon.co.uk or a UK retailer, don't invent one), a comparison table, and an FAQ. Prices mentioned in prose should be in GBP (£). No fabricated first-person testing claims ("we tested this for a month") — this is a researched buying guide, not a lab review, and the About page says so.

Order matters, on two axes: (1) near-term seasonal urgency — a Halloween topic needs to publish and index before Halloween, not after — and (2) estimated UK search demand/commercial intent within a similar timing window — higher-demand, broader-appeal topics go before niche/lower-volume ones. Both this initial ordering and any topics added later (by the self-replenishing step or the monthly audit) should follow this same logic: don't just append to the bottom blindly.
